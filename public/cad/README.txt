CAD POSTER THUMBNAILS — drop zone
=================================

Optional rendered preview images for the homepage CAD gallery cards.

- When a model has no "poster", the gallery shows an animated blueprint placeholder.
- To use a real render, put an image here (e.g. fess-rotor.png — a CAD viewport
  screenshot or render works well) and set it in /data/cad.json:
       "poster": "/cad/fess-rotor.png"
- Recommended aspect ratio ~4:3, dark background to match the theme.
