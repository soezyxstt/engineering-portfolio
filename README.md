# Adi Haditya Nursyam | Engineering Portfolio

[![CI](https://github.com/soezyxstt/port/actions/workflows/ci.yml/badge.svg)](https://github.com/soezyxstt/port/actions/workflows/ci.yml)

Portfolio covering software, AI, robotics, control systems, embedded engineering, and technical leadership.

**Live:** [adihnursyam.com](https://adihnursyam.com)

## Stack

`Next.js 16` `React 19` `TypeScript` `Tailwind CSS 4` `Framer Motion` `React Three Fiber`

## Development

```bash
bun install
bun run dev
```

Validation:

```bash
bun run lint
bun run build
```

GitHub Actions runs lint and production build checks on `main`.

## Content

- `data/portfolio.ts`: projects and case studies
- `data/about.json`: profile content
- `data/experience.json`: role history
- `docs/`: content, asset, and implementation notes

## Main routes

- `/work`: selected projects and case studies
- `/robotics`: robotics work
- `/software`: software work
- `/leadership`: leadership experience
- `/resume`: print-friendly resume
- `/contact`: contact information
